Overview

The AI Proctored Exam System is a web-based application that uses Artificial Intelligence to monitor students during online examinations. The system helps maintain exam integrity by detecting suspicious activities such as multiple faces, absence of a face, and unusual movements in real time.

Features
Real-time face detection and monitoring
Multiple face detection alerts
Head movement tracking
Automatic cheating detection
Secure online examination environment
User-friendly interface for students and administrators
Exam activity logging and reporting
Technologies Used
Python
Machine Learning
OpenCV
Flask/Django (if used)
HTML, CSS, JavaScript
SQLite/MySQL (if used)
Working
Students log in and start the examination.
The webcam continuously captures video.
AI models analyze the video feed in real time.
Suspicious activities are detected and recorded.
Administrators can review reports and monitor exam sessions.
Benefits
Reduces cheating in online exams
Ensures fair assessment
Minimizes manual invigilation efforts
Provides automated monitoring and reporting
